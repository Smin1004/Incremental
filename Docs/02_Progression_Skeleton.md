# 02. 진행 구조 뼈대

| 항목 | 값 |
|---|---|
| 상태 | 제안 |
| 최종 수정 | 2026-09-16 |
| 결정 필요 | 핵심 반복 행동, 생성기 구조, 엔딩 유무 |

테마와 무관하게 필요한 구조를 정리한다. 테마가 정해지면 명칭만 바꿔 붙인다.

## 1. 계층

```
[능동 행동] → 기본 자원 R
R → 생성기 G1..Gn 구매 → R 생산량 증가
보유 수 마일스톤 → 배율 ×2
누적 R → 프레스티지 1 (P1 화폐) → 전역 배율, 자동화, 새 생성기
누적 P1 → 프레스티지 2 (P2 화폐) → 규칙 변경, 엔딩 경로
```

## 2. 핵심 반복 행동 (결정 필요)

"무엇을 반복시킬지"의 후보. 증분 게임은 후반으로 갈수록 자동화되므로, 능동 행동은 **초반 10~30분의 몰입**과 **프레스티지 순간의 손맛**을 담당한다.

| 후보 | 내용 | 장점 | 단점 |
|---|---|---|---|
| 1. 클릭 / 홀드 | 버튼을 눌러 R을 직접 생산. 후반엔 배율로만 의미 | 가장 익숙하고 구현 1시간 | 진부함 |
| 2. 타이밍 | 게이지가 차오르면 적절한 순간에 "방출". 타이밍이 좋을수록 보너스 | 손맛. 비주얼과 결합이 쉽다 (폭발 연출) | 방치와 충돌할 수 있다 |
| 3. 배분 | 한정된 슬롯이나 에너지를 생성기에 나눠 배치 | 전략성 | UI가 복잡하고 밸런스가 어렵다 |
| 4. 선택 | 마일스톤이나 프레스티지마다 3개 중 1개 업그레이드 선택 | 회차마다 다르다. 최근 소규모 증분 게임의 공통 요소 | 카드 풀 설계 비용 |

**추천: 1 + 4.** 초반은 클릭(또는 홀드)으로 시작하고, 프레스티지마다 3택1 선택을 넣는다. 테마 A(우주)를 고를 경우 2번이 "초신성 방출"로 자연스럽게 결합되므로 대안으로 유지한다.

## 3. 생성기 구조 (제안)

| | 직접 생산 (Cookie Clicker) | 연쇄 생산 (Antimatter Dimensions) |
|---|---|---|
| 구조 | 모든 Gk가 R을 직접 생산 | Gk가 G(k-1)을 생산. G1만 R을 생산 |
| 성장 곡선 | 다항. 배율 업그레이드로 지수를 흉내 | 자연스럽게 지수. "폭발" 표현에 유리 |
| 밸런스 난이도 | 낮음 | 중간 |
| 구현 | 반나절 | 1일 |

**추천: 연쇄 생산.** 목표가 "폭발적 성장"이고, 티어가 오를수록 눈덩이처럼 커지는 구조가 비주얼과 맞물린다.

초기 수식 (모두 조정 대상):

| 항목 | 수식 | 초기값 |
|---|---|---|
| 생성기 비용 | `cost(k, n) = base_k × growth_k ^ n` | growth 1.15(G1) ~ 1.5(G8) |
| 보유 마일스톤 | 10, 25, 50, 100, 250, 500개마다 ×2 | - |
| 프레스티지 1 화폐 | `P1 = floor((누적 R / T1) ^ 0.5)` | T1은 첫 프레스티지가 45~60분에 오도록 |
| 전역 배율 | `1 + 0.1 × P1` 로 시작, 이후 업그레이드 트리 | - |
| 프레스티지 2 화폐 | `P2 = floor(log10(누적 P1) - c)` | c는 3시간 전후에 첫 P2 |

## 4. 시간축 (제안)

| 구간 | 플레이어 경험 | 시스템 |
|---|---|---|
| 0~5분 | 클릭, 첫 생성기, 화면에 첫 변화 | G1~G2 |
| 5~30분 | 생성기 8개 모두 개방, 첫 ×2들 | G1~G8, 마일스톤 |
| 30~60분 | 정체 체감 → 첫 프레스티지 | P1 개방 |
| 1~3시간 | 프레스티지 루프, 자동화 하나씩 | 자동 구매, 3택1 |
| 3~5시간 | P2 개방. 규칙 변경으로 화면 자체가 바뀐다 | P2 |
| 5~8시간 | 엔딩 조건 도달 | 엔딩 연출 |
| 이후 | 엔들리스, 도전과제 마무리 | 무한 스케일 |

## 5. 엔딩 (결정 필요)

**추천: 엔딩 있음 + 엔들리스.** 소규모 증분 게임의 Steam 리뷰에서 "끝이 있다"는 점이 만족도에 크게 기여한다. 엔딩 후에는 같은 세이브로 계속 진행할 수 있다.

## 6. 공통 시스템

- **큰 수:** double의 1e308 한계를 넘는다. BreakInfinity.cs(break_infinity.js의 C# 포트)를 쓴다. 표기법 옵션: 과학(1.23e45), 공학, 문자(1.23Qa).
- **오프라인 진행:** 기본 제공. 상한 8~24시간, 효율 50~100%. 프레스티지 업그레이드로 상향한다.
- **저장:** JSON, 30초 자동 저장, 버전 필드와 마이그레이션. 내보내기/가져오기(클립보드 텍스트)는 증분 커뮤니티 관례다.
- **자동화:** 자동 구매(티어별), 자동 프레스티지. 프레스티지로 해금한다. 후반의 반복 행동을 시스템이 대신한다.
- **밸런스 시뮬레이터:** 헤드리스로 "최적 플레이"를 자동 수행해 각 구간 도달 시간을 뽑는 스크립트. 2~3주차부터 유지한다.
