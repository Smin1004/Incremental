# 02. 진행 구조 뼈대

| 항목 | 값 |
|---|---|
| 상태 | 제안 (수식과 시간축). 구조는 확정 |
| 최종 수정 | 2026-09-18 |
| 결정 필요 | 없음. 수식 초기값은 런 로그로 조정 |

테마별 명칭은 [10_Core_Loop.md](10_Core_Loop.md)를 따른다.

## 1. 계층

```
런: [홀드 중력] → 먼지 포획 → 놓으면 행성 → 즉시 런 수입
런 종료 (스태미나 0) → 결과 화면 (태양계) → 스킬트리
스킬트리: 재화 → 스탯 노드 (먼지, 중력, 행성, 판매, 스태미나, 질량), 관문 노드 (행성 해금)
행성 해금 → 더 큰 행성 → 더 큰 런 수입 → 다음 해금   (주 성장 루프)
티어 11 도달 → 초신성 → 엔딩 → 엔들리스
```

## 2. 핵심 반복 행동 (결정됨)

**홀드로 중력 생성** (D2). 런 중에는 홀드만 한다. 후반에는 홀드 한 번이 만드는 것이 커진다.

## 3. 수식 (제안, 전부 조정 대상)

| 항목 | 수식 | 초기값 |
|---|---|---|
| 노드 비용 | `ceil(baseCost × ringCostMult[링] × growth ^ level)` | 일반 노드 1레벨 0.4 × I_k (growth 1.5), 먼지 질량 노드 1.1 × I_k (growth 1.8) |
| 관문 비용 | 약 3 × I_k | 현재 해금 비용 유지. 티어 2는 30, 티어 3은 300 |
| 링 예산 | 노드 + 관문 ≈ 9 × I_k | 링 하나에 4~6런. 조정은 `ringCostMult` 하나로 ([12](12_SkillTree_Spec.md) §7) |
| 기준 수입 I_k | 링 k 진입 직후 봇 3런 평균 | 초안 I_1 = 12, I_(k+1) = 8 × I_k. 가정하지 말고 잰다 |
| 먼지 질량 | `1.5 ^ n` | 티어 6 이후 주력 |
| 스태미나 | 최대 60 + 10/레벨. 홀드 1/초, 대기 0.2/초 | 첫 런 1분, 후반 5~10분 |
| 런당 성장 목표 | 런 n 수입 / 런 n−1 수입 | 초반 ×1.3~2.0, 중반 ×1.1~1.3, 해금 런 ×3 이상 |

모든 값은 double 안에 있다.

## 4. 시간축 (제안, 2~4시간, 40~70런)

| 구간 | 런 | 플레이어 경험 | 시스템 |
|---|---|---|---|
| 0~5분 | 1~4 | 홀드, 첫 소행성, 첫 결과 화면, 첫 업그레이드 | 티어 1~2 |
| 5~20분 | 5~15 | 먼지 폭증. 화면이 가득 차는 첫 런. 티어 5까지 | 먼지 상한, 중력 반경 |
| 20~60분 | 15~30 | 티어 6~8. 런이 3~5분으로 길어진다 | 먼지 질량, 스태미나 |
| 1~2시간 | 30~50 | 항성 점화. 화면이 밝아진다 | 티어 9~10 |
| 2~4시간 | 50~70 | 청색 거성 → 초신성 → 엔딩 | 티어 11 |
| 이후 | - | 엔들리스, 도전과제 마무리 | 새 시스템 없음 |

## 5. 엔딩 (결정됨)

**엔딩 있음 + 엔들리스** (D4). 조건은 티어 11 → 초신성 (E5 기본값).

## 6. 공통 시스템

- **숫자:** `double`. 표기법은 과학(1.23e9)과 문자(1.23B) 중 옵션.
- **오프라인 진행:** 없음. 런 중 앱을 끄면 그 런은 종료된 것으로 처리한다(수입은 유지).
- **저장:** 런 사이 상태를 JSON으로. 런 종료마다 자동 저장. 버전 필드와 마이그레이션.
- **자동화:** 없음. 홀드가 게임이다. 판매는 즉시 합산이므로 자동화할 것이 없다.
- **밸런스 검증:** 런별 수입과 길이를 로그로 남긴다. 전체 플레이 3회 이상, §3의 런당 성장 목표와 비교한다. 헤드리스 시뮬레이터(S2)는 선택.
