# 02. 진행 구조 뼈대

| 항목 | 값 |
|---|---|
| 상태 | 제안 (수식과 시간축). §2, §5는 결정됨 |
| 최종 수정 | 2026-09-16 |
| 결정 필요 | 없음. 수식 초기값은 시뮬레이터로 조정 |

테마와 무관한 구조를 정리한다. 테마별 명칭은 [10_Core_Loop.md](10_Core_Loop.md)를 따른다.

## 1. 계층

```
[홀드 중력] → 먼지 포획 → 행성 생성 → 판매 → 재화 R
R → 업그레이드 (먼지, 중력, 행성, 판매, 궤도)
궤도 행성 → 스스로 먼지 흡수 → 성장 (방치 경로, E1-B안)
티어 11 도달 → 프레스티지 1 (중원소) → 영구 배율, 해금
중원소 누적 → 프레스티지 2 (은하 화폐) → 스케일 전환, 엔딩 경로
```

## 2. 핵심 반복 행동 (결정됨)

**홀드로 중력 생성** (D2, 2026-09-16). 후반은 자동화가 대신하므로, 홀드는 초반 10~30분의 몰입과 큰 행성을 직접 만드는 손맛을 담당한다.

검토했던 다른 후보(클릭, 타이밍, 배분, 3택1 선택)는 기록만 남긴다. 3택1 선택은 프레스티지 보상 형태로 붙일 수 있어 백로그 S3에 유지한다.

## 3. 생성기 구조

원래 "직접 생산(Cookie Clicker) / 연쇄 생산(Antimatter Dimensions)" 중 택일이었으나, 컨셉 확정으로 **궤도 행성이 생성기 역할**을 하게 되어 이 결정은 E1(10 문서 §4.1)로 대체되었다. 궤도 행성이 먼지를 흡수해 티어가 오르는 구조가 자연스러운 연쇄 생산이다.

비용 수식은 업그레이드에 그대로 적용한다. 전부 조정 대상.

| 항목 | 수식 | 초기값 |
|---|---|---|
| 업그레이드 비용 | `cost(u, n) = base_u × growth_u ^ n` | growth 1.15(저렴한 축) ~ 1.5(강한 축) |
| 행성 해금 비용 | 해당 티어 기본 판매가 × 20~50 | 직전 티어 행성을 20~50개 팔면 다음 티어 |
| 보유 마일스톤 | 티어별 판매 누적 10, 25, 50, 100, 250, 500개마다 그 티어 판매가 ×2 | - |
| 프레스티지 1 화폐 | `중원소 = floor((누적 판매액 / T1) ^ 0.5)` | T1은 첫 초신성이 45~90분에 오도록 |
| 중원소 배율 | `1 + 0.1 × 중원소` 로 시작, 이후 업그레이드 트리 | - |
| 프레스티지 2 화폐 | `은하 = floor(log10(누적 중원소) - c)` | c는 3~4시간에 첫 은하 |

## 4. 시간축 (제안)

| 구간 | 플레이어 경험 | 시스템 |
|---|---|---|
| 0~5분 | 홀드, 첫 소행성, 첫 판매 | 티어 1~2, 업그레이드 3개 |
| 5~20분 | 먼지 폭증, 티어 5까지 해금, 첫 궤도 슬롯 | 먼지 상한, 중력 반경, 궤도 |
| 20~45분 | 방치 경로 체감, 자동 판매 | 궤도 행성 성장, 자동화 |
| 45~90분 | 항성 점화 → 청색 거성 → 첫 초신성 | 프레스티지 1 |
| 1.5~3시간 | 초신성 루프, 중원소 트리 | 반복, 3택1(S3 채택 시) |
| 3~4시간 | 첫 은하. 화면 스케일 전환 | 프레스티지 2 |
| 5~8시간 | 은하 완성, 엔딩 | 엔딩 연출 |
| 이후 | 엔들리스, 도전과제 마무리 | 무한 스케일 |

## 5. 엔딩 (결정됨)

**엔딩 있음 + 엔들리스** (D4, 2026-09-16). 엔딩 조건(E5)은 10 문서 §4.5의 "은하 완성" 안.

## 6. 공통 시스템

- **큰 수:** double의 1e308 한계를 넘는다. BreakInfinity.cs(break_infinity.js의 C# 포트)를 쓴다. 표기법 옵션: 과학(1.23e45), 공학, 문자(1.23Qa).
- **오프라인 진행:** 기본 제공. 상한 8~24시간, 효율 50~100%. 프레스티지 업그레이드로 상향한다. 물리 대신 궤도 행성의 기대 흡수율 × 시간으로 계산한다 (10 문서 §4.6).
- **저장:** JSON, 30초 자동 저장, 버전 필드와 마이그레이션. 내보내기/가져오기(클립보드 텍스트)는 증분 커뮤니티 관례다.
- **자동화:** 자동 판매(티어별), 자동 해금, 자동 프레스티지. 프레스티지로 해금한다.
- **밸런스 시뮬레이터:** 헤드리스로 "최적 플레이"를 자동 수행해 각 구간 도달 시간을 뽑는 스크립트. 2~3주차부터 유지한다. 오프라인 수식과 같은 코드를 쓴다.
