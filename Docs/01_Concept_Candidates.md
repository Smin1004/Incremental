# 01. 컨셉 후보: 테마와 비주얼 엔진

| 항목 | 값 |
|---|---|
| 상태 | 제안 |
| 최종 수정 | 2026-09-16 |
| 결정 필요 | 후보 중 1개 선택, 또는 룩 테스트할 2개 선택 |

## 0. 전제

아트 에셋 없이 "폭발적 성장"을 보여줘야 한다. 따라서 비주얼 엔진은 다음 조건을 만족해야 한다.

1. **입력이 숫자다.** 자원량, 생성기 수, 배율이 그대로 파라미터로 들어간다.
2. **지수적으로 커져도 보인다.** 1과 1e30을 화면에서 다르게 보여줄 수 있어야 한다. 수량은 어느 시점부터 밀도, 밝기, 속도, 복잡도로 바꿔 표현한다.
3. **1~2일 안에 프로토타입이 나온다.**
4. **스크린샷이 예쁘다.** 스토어 캡슐과 트레일러를 게임 화면에서 뽑아야 한다.

## 2. 추천

**1순위: A. 우주 / 중력.**
- 폭발적 성장 표현이 가장 직관적이다. 파티클 10개와 100만 개는 설명 없이 다르다.
- 프레스티지의 서사(수축 → 특이점 → 새 우주)가 테마에서 공짜로 나온다.
- Unity가 가장 잘 하는 것이 파티클이다. 진짜 N체 시뮬레이션은 필요 없다. 각 파티클이 가장 가까운 인력원을 공전하는 가짜 중력이면 충분하다.
- 캡슐 이미지와 트레일러가 잘 나온다.

**2순위: B. 프랙탈 / 성장.** 구현 비용이 가장 낮다. 단조로움은 프레스티지마다 규칙(가지 각도, 분기 수, 색)을 바꿔 해결한다.

**절충안: A + C.** 우주 테마에 C의 궤도 수학(에피사이클)을 쓰면, 인력원이 늘수록 궤도가 정교해져 "커짐"과 "정교해짐"을 동시에 얻는다. 비용은 A와 같다.

## 3. 결정 방식 (제안)

후보를 문서로 고르지 말고, **1주차에 2개를 각각 1일씩 룩 테스트**한 뒤 고른다. 룩 테스트의 합격 기준:

- 슬라이더 하나(0~1)를 올렸을 때 "초반 / 중반 / 폭발" 3단계가 확연히 다르게 보인다.
- 60fps를 유지한다.
- 그 화면을 캡처한 것이 스토어 스크린샷으로 쓸 만하다.

## 4. 후보 A 상세 (선택 시 확장)

- 중심에 특이점. 기본 자원(예: 물질)은 파티클로 표현한다. 시각 캡은 GPU 인스턴싱 기준 약 20만~100만.
- 생성기 티어 = 인력원(별, 성단, 은하핵). 티어가 오를수록 더 바깥 궤도, 더 큰 반지름.
- 배율 업그레이드 = 색온도(적 → 백 → 청), 궤도 속도, 글로우 강도.
- 마일스톤 = 초신성 연출(파티클 방출 + 화면 플래시). 광과민성 옵션 필수.
- 프레스티지 1 = 빅 크런치. 모든 파티클이 중심으로 빨려 들어간 뒤 새 우주로 재팽창.
- 프레스티지 2 = 다중우주. 배경에 이전 우주들이 작게 남는다.
- 숫자가 시각 캡을 넘으면 파티클 크기, 밝기, 궤도 두께로 로그 스케일 표현.

## 5. 후보 B 상세 (선택 시 확장)

- 중심에 씨앗. 기본 자원은 가지 끝의 잎/결정 수.
- 생성기 티어 = 분기 깊이. 깊이 k의 가지 수는 `분기수^k`로 지수 증가하므로 증분 수식과 자연스럽게 맞는다.
- 배율 업그레이드 = 가지 굵기, 색, 잎 밀도.
- 마일스톤 = 개화. 모든 가지 끝에서 동시에 파티클 방출.
- 프레스티지 1 = 씨앗으로 회귀. 규칙(각도, 분기 수, 대칭) 중 하나가 바뀐다.
- 프레스티지 2 = 숲. 배경에 이전 나무들이 남고, 새 나무가 자란다.
- 성능: 깊이 10 이상은 가지를 텍스처로 구워 배경 처리, 최신 깊이만 실시간.
