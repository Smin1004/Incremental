# 13. 결과 화면 태양계 스펙 (구현 인계)

| 항목 | 값 |
|---|---|
| 상태 | 방향 확정 (S13 채택, 2026-09-18). 수치는 제안 |
| 최종 수정 | 2026-09-18 |
| 대상 | 구현 세션 |
| 시점 | 3주차. 최소 버전 0.5일, 전체 1.5일. 표면 셰이더는 4주차 |

## 1. 목적

결과 화면에서, 이번 런에 만든 행성들이 중심 항성을 공전하는 태양계를 보여준다. 중심 항성은 결과 화면에만 있는 보여주기용이다.

- **행성다움.** 공전과 자전, 명암.
- **퇴장의 행선지.** 런 중 생성된 행성이 "팔려서 사라지는" 대신 궤도로 떠난다.
- **결과 화면이 성장 그림이 된다.** 지난 런보다 붐비는 태양계. 티어를 해금하면 궤도가 하나 는다.
- **스토어 이미지.** 먼지 화면보다 태양계가 캡슐로 강하다.

## 2. 런 중: 퇴장 연출

현재는 생성 위치에 1.5초(`planetLifetimeSec`) 보이다가 사라진다. 다음으로 바꾼다.

```
생성 (팝 0.15초) → 제자리에서 자전 0.4초 → 소실점으로 이동하며 축소, 페이드 0.8초
```

- 소실점은 **화면 우상단 바깥, 고정.** 매번 같은 방향이어야 "어딘가에 모인다"를 배운다.
- 그 방향의 화면 가장자리에 희미한 빛을 둔다. 중심 항성의 암시다. 색은 중심 항성 단계(§3)를 따른다.
- 입력을 막지 않는다. 떠나는 동안에도 홀드할 수 있다. 풀 구조는 그대로.
- 새 파라미터: `planetHoldSec` 0.4, `planetDepartSec` 0.8, `vanishPoint` (정규화 좌표 1.05, 1.05).

## 3. 결과 화면 구성

### 배치
- 중심 항성은 화면 중앙에서 약간 오른쪽. 왼쪽에 결과 패널.
- 패널: 런 수입(카운트업), **지난 런 대비 배율**, 티어별 개수, 최고 기록, [스킬트리] 버튼(Space).

### 궤도
- **해금한 티어 중 1~8**마다 궤도 하나. 해금 전에는 그리지 않는다. 궤도 수가 게임 내내 늘어난다.
- 반지름 `r_t = r0 + (t − 1) × step`. 1080p 기준 `r0` 110px, `step` 52px. 티어 8이 474px로 화면 높이에 들어온다.
- 궤도선은 가는 원, 알파 0.15. 이번 런에 행성이 있는 궤도는 0.3.

### 행성
- 개수는 `RunRecord.tierCounts`. **이번 런 것만** 보여준다. 누적하지 않는다.
- 표시 크기는 `sizePx × 0.5`.

| 티어 | 개별 표시 | 초과 시 |
|---|---|---|
| 1~3 | 16개까지 | **소행성대.** 점 `min(개수, 240)`개, 반지름 흔들림 ±8px, 크기 2~4px. 옆에 `×N` |
| 4~8 | 12개까지 | 12개 + `×N` |

- 공전: 반시계. 각속도 `ω(r) = ω0 × (r0 / r)^1.5`, `ω0` 40°/초. 안쪽이 빠르다. 초기 위상은 균등 분할 + 작은 무작위.

### 항성 (티어 9~11)
- 궤도에 놓지 않는다. 청색 거성이 중심 항성을 공전하면 어색하다.
- 이번 런에 만든 항성은 **배경 하늘에 밝은 별로** 추가한다. 런당 최대 20개, 나머지는 패널 숫자로만.
- 행성은 궤도에, 항성은 하늘에.

### 중심 항성
외형만 진행도를 따른다. 게임 효과는 없다. `MetaState.highestTierCreated` 기준.

| 조건 | 중심 | 모습 |
|---|---|---|
| 9 미만 | 원시성 | 희미한 주황 글로우, 느린 맥동 |
| 9 | 적색 왜성 | 작은 붉은 원 + 글로우. 처음 도달한 런의 결과 화면에서 **점화 연출** |
| 10 | 태양형 항성 | 노란 원, 더 큰 글로우 |
| 11 | 청색 거성 | 크고 푸른 흰색. 이어서 초신성 엔딩 (10 §4.4) |
| 엔딩 후 | 블랙홀 | 검은 원 + 밝은 강착 원반. 상세는 [15](15_Ending_Spec.md) §5 |

## 4. 행성다움: 명암과 자전

무늬 없는 원은 돌려도 티가 나지 않는다. 그래서 두 단계로 간다.

- **3주차, 셰이더 전.** 원 위에 어두운 초승달을 겹친다. 중심 항성 반대쪽이 어둡다. 공전하면 그림자 방향이 따라 돈다. 이것만으로 "무언가를 돌고 있는 구체"로 읽힌다.
- **4주차, 셰이더.** 조명 방향 + 표면 노이즈와 띠의 UV 스크롤이 자전이다. 자전 속도는 티어별. 가스 행성(티어 7)에 고리.
- 런 화면의 행성에도 같은 명암을 쓴다. 광원은 소실점 방향.

## 5. 등장 연출

- 결과 화면에 들어오면 행성들이 소실점 방향(우상단)에서 날아와 궤도에 안착한다. 티어 낮은 순, 전체 1.2초.
- 런 수입 카운트업과 같은 시간에 끝난다.
- **Space나 클릭으로 즉시 생략.** 생략하면 최종 상태로 점프.
- 플래시류에만 `effectIntensity`를 곱한다.

## 6. 데이터와 저장

- 추가 저장 없음. `runHistory`의 마지막 `RunRecord`, `unlockedMaxTier`, `highestTierCreated`만 읽는다.
- 런 기록이 없는 첫 실행: 빈 궤도 하나 + 원시성.
- 새 수치는 전부 데이터 에셋에. 코드 상수 없음.

## 7. 문구

궤도에 남는데 "판매"라고 하면 어색하다. 숫자 구조는 그대로 두고 표시 문구만의 문제다. 후보: 편입, 등록. 로컬라이제이션 시점(6~7주차)에 정한다 (백로그 D10). 그때까지 문자열 키와 코드의 `sale`은 그대로.

## 8. 범위

| 버전 | 내용 | 비용 |
|---|---|---|
| 최소 | 궤도선, 원, 공전, 패널 | 0.5일 |
| 전체 | + 소행성대, 초승달 명암, 등장 연출, 중심 항성 단계, 런 중 퇴장 연출 | 1.5일 |
| 셰이더 | + 표면 무늬, 자전, 고리 | 4주차 행성 셰이더 작업에 포함 |

## 9. 합격 기준

- 런 1과 런 10의 결과 화면을 나란히 놓으면 성장이 한눈에 보인다.
- Space 두 번(결과 → 트리 → 다음 런)으로 3초 안에 다음 런.
- 소행성 500개를 만든 런에서도 60fps.
- 캡처가 스토어 스크린샷으로 쓸 만하다.
