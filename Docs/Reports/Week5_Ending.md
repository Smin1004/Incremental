## 1. 만든 것

**A. 4주차 검토 반영 (15 §3)**
- **섬광 규칙**: 방사형 섬광 셰이더 `Incremental/Flash` + 공용 `ScreenFlash`. 밝기는 광원에서 가우시안으로 떨어져 `flashRadiusPx`(540px = 1080p 화면 높이의 절반)에서 중심의 `flashEdgeShare`(0.3)배가 된다. 최고 알파 상한 `flashAlphaCap` 0.35(실행 중에도 잘라낸다), 상승 `flashMinRiseSec` 0.1초 이상, 전부 `EffectIntensity`를 곱한다. 런 화면 점화, 결과 화면 점화(13 §3), 초신성 폭발이 모두 이 규칙을 쓴다. 첫 점화 최고 알파 0.7 → 0.3, 상승 0.06 → 0.1초.
- **결과 패널 `▼` 숨김**: 이번 런에 만든 티어만 행으로 보이고 증감 칸에는 `▲`와 "새 천체"만 쓴다(`ResultMath.ShownIncrease`).
- **먼지**: ① 중력장 밖 먼지 밝기 0.5배(`dustOutsideDim`). 반경 밖 60px 띠에서 부드럽게 바뀌고, 홀드를 시작·멈출 때 0.25초에 걸쳐 바뀐다. ② 팔레트마다 먼지는 따뜻한 색(원시성은 연한 호박색), 배경 별은 무채색(`starTint` 0.88~0.94). 먼지 정점 색을 선형으로 변환해 지정한 색 그대로 보인다(4주차 알려진 문제 해결). ③ 늘어난 먼지는 폭 0.5배(`dustStreakWidth`), 꼬리 끝이 뾰족하다(셰이더). 가늘어진 만큼 끌려오는 먼지 밝아짐 0.8 → 1.5, 늘어난 먼지 감광 0.7 → 1.
- **하늘 항성 "새 천체"**: 처음 만든 항성 티어는 하늘 별 하나가 궤도와 같은 맥동(크기 +60%, 글로우)과 라벨을 받는다. 하늘 별 개수 한도를 넘어도 그 하나는 그린다.
- **소행성대 점 밝기 1.5배**(`orbitBeltDotBrightness`).
- **`ringCostMult[1]` 1.5 → 1.3** (에셋, `SkillTreeSeed`).

**B. 초신성 엔딩 (15 §4)**
- **발생**: 청색 거성이 만들어지는 순간 `endingRun == 0`이면. 그 청색 거성은 형성 중이던 천체의 표면과 크기를 이어받아 그 자리에 남고, 첫 항성 점화 연출(큰 빛 고리 + 섬광 0.3)을 받는다.
- **런 화면(약 3초)**: 입력 무시, 먼지 생성 중지, 모든 먼지가 반경 제한 없이 청색 거성으로 떨어진다(`DustField.TickPull`: 가속 1,000px/s², 최고 1,400px/s, 옆 속도 감쇠 3/s, 항성 원판에 닿으면 흡수). 2초 뒤 1초 동안 어두워지고 종료 사유 `ending`으로 끝난다. 이 3초 동안 스태미나와 런 시간은 멈춘다. 끌려오는 먼지는 어둡게 하지 않고 항성 가까이에서 더 밝다.
- **런 처리**: `ending`은 스태미나 런처럼 전체 런이다(배율, 배율 기준, 최고 기록). 남은 스태미나는 버린다. 로그 `end_reason`은 `ending`.
- **결과 화면 시퀀스**(`EndingView`, 결과 화면 진입 기준 초): 패널 없이 태양계를 화면 중앙에, 중심은 청색 거성. 0~1.2 기존 등장 → 1.2~3.5 맥동이 0.7Hz·2%에서 4Hz·14%로 커지고 색이 흰빛으로(85%) → 3.5~4.3 한 점으로 수축, 코로나 크기가 먼저 줄어든다 → 4.3~4.8 섬광(최고 0.35, 상승 0.12초)과 중심광, 항성이 먼지 900개를 뿜는다 → 4.8~8.0 충격파 고리가 60px에서 1,250px로 퍼지며 닿은 행성·소행성대 점·하늘 항성을 바깥으로 날아가는 먼지로 바꾸고 궤도선을 0.25초에 지운다 → 8.0~12.0 먼지가 감속해 7px/s로 떠돌고(화면 가장자리에서 튕긴다), 팔레트가 3초에 걸쳐 잔해 성운으로, 8.5초부터 블랙홀이 3초에 걸쳐 나타난다 → 12~37 크레딧 5줄(한 줄 5초, 페이드 1초) → "계속하기 (Space)" → 스킬트리 → 엔들리스.
- 결과 화면 시퀀스는 런 화면의 암전에서 1초에 걸쳐 밝아지며 시작한다.
- **건너뛰기**: 4.3초 전에는 입력을 받지 않는다. 이후 Space나 클릭은 남은 천체를 모두 흩뜨리고 먼지를 6초 앞당겨 정착시킨 뒤 "계속하기"로 간다. 클릭은 버튼을 뗄 때 인식한다.
- **연출 강도 0**: 섬광과 중심광 없음, 충격파 고리는 0.3배(강도 i에서 `lerp(0.3, 1, i)`). 흩어짐, 팔레트, 블랙홀은 그대로.
- **크레딧**: `UIStrings` 키 `credits.title` ~ `credits.last`에 15 §4.4 표의 자리표시 값을 그대로 넣었다.
- **저장과 복구**: `MetaState.endingRun`, `endingSeen`. JsonUtility가 없는 필드를 기본값으로 두므로 세이브 버전은 올리지 않았다(테스트). 엔딩 런이 끝나 저장될 때 `endingRun`이 기록되고, "계속하기"가 뜨는 순간(끝까지 보거나 건너뜀) `endingSeen = true`로 저장한다. 실행 시 `endingRun > 0`이고 `endingSeen == false`면 결과 화면 대신 시퀀스를 처음부터 재생한다. 런 화면의 3초 도중 강제 종료되거나 앱을 끄면 그 런을 `ending`으로 마감한다(`PendingRun.ending`).
- **디버그**: **End 키**로 엔딩 시퀀스 재생(런 사이에만, 마지막 런의 태양계). 저장을 바꾸지 않는다.

**C. 엔들리스 (15 §5)**
- **블랙홀**(중심 항성 단계 5): Planet 셰이더에 표면 타입 `BlackHole`을 추가했다. 검은 원판, 가장자리의 푸른 빛, 적도면의 강착 원반(안쪽 뜨거운 색 → 바깥 자홍, 스핀 속도로 도는 줄무늬, 행성 원판에 가려지는 앞뒤 처리). 모양은 `GameParams.blackHoleLook`, 원판 56px.
- **잔해 성운 팔레트**(단계 5): 어두운 배경 + 청록·자홍 성운 노이즈(`Starfield` 셰이더, `BackdropPalette.nebula*`). 먼지는 따뜻한 산호·호박색, 별은 무채색.
- 단계는 `endingRun > 0`으로 정한다(`BackdropView.NaturalStage`). 런·결과·트리 화면이 모두 잔해 팔레트를 쓰고, 결과 화면 중심은 블랙홀, 런 화면 소실점 빛은 블랙홀 글로우 색이다. 게임 규칙은 그대로다(청색 거성은 계속 하늘의 항성).

**D. 봇 완주와 링 스냅샷 (15 §6)**
- 봇은 관문을 산 직후 `save.json`을 `snapshots/ring_k.json`으로 복사한다. 엔딩 런이 끝나면 폭발 이후 곧바로 건너뛰고 계속하기 → 구매 → 엔들리스 1런을 한 뒤 멈춘다(`stopAfterEndlessRuns` 1).
- 에디터 메뉴 **Incremental / Snapshots / Load...**(파일 선택)와 **Open Folder**. 플레이 중이면 진행 중인 런을 버리고 즉시 그 스냅샷으로 바뀌고, 플레이 중이 아니면 스냅샷이 `save.json`이 된다. 코드로는 `SnapshotMenu.LoadRing(k)`.
- 완주 결과는 5절.

**데이터와 검증**
- 새 수치는 전부 `GameParams`(Flash rule, Dust look, Supernova ending run screen / result screen, Credits 절, `blackHoleLook`, 팔레트 5번)에 있고 에셋에 저장했다. 봇 설정 2개는 기존 봇 설정처럼 `AutoplayBot` 필드다.
- Validate Data 추가: 섬광 규칙(모든 섬광의 최고 알파 ≤ 상한, 상승 ≥ 최소), 먼지 따뜻한 색·별 무채색(경고), 먼지 새 수치 범위, 엔딩 타임라인 순서, 충격파·먼지·크레딧 수치, `blackHoleLook`이 BlackHole 표면인지와 강착 원반, 팔레트·중심 항성 크기가 단계 5개(잔해 포함)인지, 크레딧 키.
- 새 테스트 16개(`Week5Tests`): 섬광 곡선과 규칙 검사, 결과 패널 증가분만, 먼지·별 색, 엔딩 발생 조건, 엔딩 런이 전체 런이고 `endingRun`을 기록, 저장 왕복과 구 세이브 기본값, 엔딩 도중 강제 종료 → ending 런, 단계(잔해), 기본 팔레트 5개와 블랙홀, 엔딩 수치 검사, 크레딧 자리표시, 기본 수치로 1080p 화면 끝의 먼지까지 2초 안에 흡수, 스냅샷 경로.

## 8. 알려진 문제

- 캡처는 디버그 코드로 만든 장면이다(`bot_*` 제외). 엔들리스 결과 화면의 행성 수도 디버그 코드로 넣어 수입이 0으로 나온다.
- 성능은 에디터 수치다. 빌드는 재지 않았다.
- 엔딩 결과 화면 시퀀스는 실시간(unscaled)이다. 봇 측정 배속과 관계없이 건너뛰기까지 4.3초 걸린다.
- 스냅샷을 불러오면 진행 중인 런은 기록 없이 버리고, 재생 중인 엔딩 시퀀스는 멈춘다.
- 섬광 기준이 광원 위치라서 화면 가장자리 근처에서 만든 항성의 섬광은 그 가장자리를 0.3배보다 밝게 한다.
- "계속하기"가 뜬 뒤에는 앱을 꺼도 시퀀스를 다시 보여 주지 않는다(`endingSeen`이 이미 true).
- 동작 확인 흔적(세이브, 로그)은 persistentDataPath의 `week5_tests\`로 옮겼다. 지금 세이브는 없다(다음 실행은 새 게임). `snapshots\`는 6주차용으로 남겼다.
