## 4. 용어

| 용어 | 정의 |
|---|---|
| 먼지 | 기본 자원 파티클. 화면을 떠돈다 |
| 중력원 | 홀드 중 커서 위치. 먼지를 끌어당긴다 |
| 포획 반경 | 중력원 주위에서 "모인 것"으로 집계되는 범위 |
| 질량 | 먼지 개수 × 먼지 1개 질량. 행성 티어를 결정한다 |
| 천체 / 행성 | 질량 임계를 넘어 생성된 객체. 티어 1~11 |
| 런 | 스태미나 가득에서 0까지의 한 회차 |
| 런 수입 | 한 런 동안 생성된 행성 판매가의 합 |
| 시각 캡 | 화면에 그릴 수 있는 최대 먼지 수. 이 이상은 질량으로 표현 |
| 스탯 노드 | 스킬트리에서 스탯 하나를 올리는 노드 |
| 관문 노드 | 스킬트리에서 천체 티어를 해금하는 노드. 링의 경계 |
| 링 | 같은 `minTier`를 가진 노드들. 관문 k를 사면 링 k가 열린다 |
| I_k | 링 k 진입 직후의 평균 런 수입. 링 비용의 기준. 봇으로 실측 |
| 소실점 | 런 중 생성된 행성이 떠나는 화면 우상단 바깥의 고정점 |
| 중심 항성 | 결과 화면에만 있는 보여주기용 항성. 외형이 최고 항성 티어를 따라간다 |
