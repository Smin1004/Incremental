| # | 제안 | 이유 | 비용 |

| S4 | 캡슐 이미지 생성 도구를 게임 안에 내장 | 아트 없이 스토어 이미지를 뽑아야 한다. 고해상도 캡처 + 타이틀 오버레이 | 0.5일 |
| S5 | 광과민성 옵션을 첫 구현부터 | 초신성, 항성 점화가 핵심 연출. 나중에 붙이면 전부 다시 손본다 | 초기 0.5일 |
| S6 | 한/영 동시 개발 | 나중에 붙이면 UI 전부 재작업. 문자열 테이블을 처음부터 | 초기 0.5일 |

| S8 | 홀드 대신 클릭 토글 접근성 옵션 | 몇 시간 홀드는 손목에 무리. 리뷰 리스크 | 0.5시간 |

## 4. 용어

| 용어 | 정의 |
|---|---|
| 먼지 | 기본 자원 파티클. 화면을 떠돈다 |
| 중력원 | 홀드 중 커서 위치. 먼지를 끌어당긴다 |
| 포획 반경 | 중력원 주위에서 "모인 것"으로 집계되는 범위 |
| 질량 | 먼지 개수 × 먼지 1개 질량. 행성 티어를 결정한다 |
| 천체 / 행성 | 질량 임계를 넘어 생성된 객체. 티어 1~11 |
| 궤도 슬롯 | 판매하지 않고 유지할 수 있는 행성 수 (E1-B) |
| 중원소 | 프레스티지 1 화폐 |
| 은하 화폐 | 프레스티지 2 화폐 |
| 시각 캡 | 화면에 그릴 수 있는 최대 먼지 수. 이 이상은 질량으로 표현 |
