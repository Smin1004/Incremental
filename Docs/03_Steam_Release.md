# 03. Steam 출시 체크리스트

## 1. 계정 / 행정 (개발자 본인이 직접)

- **지금 시작 권장 (2026-09-19).** 개발이 예상보다 빨라 Steam 쪽 대기 시간이 병목이 된다
- **앱 수수료를 낸 날부터 30일이 지나야 출시할 수 있다.** "출시 예정" 페이지 2주 공개와 기간이 겹쳐도 된다. 날짜 일정은 [16](16_Release_Roadmap.md) §3
- 2026년 10월 Next Fest는 등록 마감(8/31)이 지났다. 다음은 2027년 2월(2/22~3/1, 등록 마감 1/10)
- Steamworks 파트너 가입. Steam Direct 수수료 앱당 $100 (매출 $1,000 도달 시 환급)
- 세금 인터뷰(W-8BEN), 은행 정보. 가입부터 스토어 페이지 생성 가능까지 수일
- 회사명 결정. 현재 Unity 설정은 `DefaultCompany`

## 2. 스토어 페이지

- **커밍순 페이지는 출시 최소 2주 전 공개.** 찜(wishlist)을 모으려면 4~8주 전 권장. 7주차 초안 공개
- 스토어 페이지 검토 3~5영업일. 빌드 검토는 별도
- 필요 이미지 (아트 없이 게임 화면 + 타이포로 제작):
  - 메인 캡슐 616×353, 헤더 460×215, 소형 231×87, 세로 374×448
  - 라이브러리 캡슐 600×900, 라이브러리 히어로 3840×1240, 로고 1280×720 (투명)
  - 스크린샷 1920×1080 5장 이상. 구성: 런 화면, 태양계 초반, 태양계 후반, 별자리 스킬트리, 항성 점화
- **캡슐 방향: 행성이 가득한 태양계(결과 화면)를 메인으로.** 4주차 `Reports/Week4_Screens/result_full.png`가 이미 이 수준이다. 먼지 화면은 축소하면 별 배경으로만 보인다 (1주차 보고 §7)
- 트레일러 30~60초. 첫 5초에 홀드로 행성이 만들어져 궤도로 떠나는 장면. 이후 런마다 붐비는 태양계 → 별자리 스킬트리 → 먼지 폭증 → 항성 점화 → 초신성 순
- 태그: Idler, Clicker, Incremental, Relaxing, Minimalist, Abstract, Casual, Singleplayer
- 설명: 한국어, 영어

## 3. 데모

- 레퍼런스 두 게임(You Know The Drill, Bills Must Be Paid) 모두 Steam 데모가 있다. 이 장르에서 데모는 관례
- 데모 분량: 첫 20~30분 (티어 5까지). 먼지 폭증 순간까지 보여주고 끊는다
- Next Fest 참가는 선택. 일정이 맞으면 찜 확보에 가장 효과적

## 4. 빌드 / 기술

- Windows x64 필수. Linux는 Unity 빌드로 저비용 추가 가능. Steam Deck 확인(Proton) 권장
- Steamworks.NET 연동: 도전과제, 클라우드 세이브, 오버레이
- 도전과제 20~30개. 티어 해금, 특이 천체, 누적 판매, 엔딩. 증분 게임 유저에게 사실상 필수 콘텐츠
- 클라우드 세이브: 로컬 세이브 파일 경로 지정 (Auto-Cloud)
- 창 모드/전체 화면, 해상도, 프레임 제한, 백그라운드 실행 시 저부하 모드

## 5. 옵션 / 접근성

- 연출 강도 0~100% (플래시, 폭발, 화면 흔들림). 파티클과 초신성이 핵심이므로 필수
- 홀드 대신 클릭 토글
- 숫자 표기법 선택
- UI 스케일

## 6. 가격 / 마케팅 (제안)

- **가격 $3.99.** You Know The Drill과 같다. Bills Must Be Paid는 $6.99이지만 아트 없는 첫 작품이므로 상단은 피한다. 지역 가격은 Steam 권장값
- 출시 할인 10~15%
- 커뮤니티: r/incremental_games (자체 홍보 규칙 확인), 국내 커뮤니티, 개발 타임랩스 영상
- 리뷰 확보: 출시 초기 리뷰 10개가 "긍정적" 표시의 기준

## 7. 출시 전 최종 점검

- [ ] 세이브 마이그레이션 테스트 (구버전 세이브 로드)
- [ ] 앱 종료 후 복귀 시 상태 복원 확인
- [ ] 엔들리스 장시간 플레이 후 메모리와 성능 확인
- [ ] 엔들리스 포함 최종 수치가 double 범위 안인지 확인
- [ ] 도전과제 전부 달성 가능 확인
- [ ] 연출 강도 0%에서 게임 진행에 지장이 없는지 확인
- [ ] 외부 테스터 3명 이상, 엔딩 도달 시간 기록 (목표 2~4시간)
