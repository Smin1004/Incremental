# 03. Steam 출시 체크리스트

| 항목 | 값 |
|---|---|
| 상태 | 검토중 |
| 최종 수정 | 2026-09-16 |
| 결정 필요 | 가격, Next Fest 데모 참가 여부, 지원 OS |

## 1. 계정 / 행정 (개발자 본인이 직접)

- Steamworks 파트너 가입. Steam Direct 수수료 앱당 $100 (매출 $1,000 도달 시 환급)
- 세금 인터뷰(W-8BEN), 은행 정보. 가입부터 스토어 페이지 생성 가능까지 수일
- 회사명 결정. 현재 Unity 설정은 `DefaultCompany`

## 2. 스토어 페이지

- **커밍순 페이지는 출시 최소 2주 전 공개.** 찜(wishlist)을 모으려면 4~8주 전 권장
- 스토어 페이지 검토 3~5영업일. 빌드 검토는 별도
- 필요 이미지 (아트 없이 게임 화면 + 타이포로 제작):
  - 메인 캡슐 616×353, 헤더 460×215, 소형 231×87, 세로 374×448
  - 라이브러리 캡슐 600×900, 라이브러리 히어로 3840×1240, 로고 1280×720 (투명)
  - 스크린샷 1920×1080 5장 이상
- 트레일러 30~60초. 게임 내 "폭발" 구간 캡처가 곧 트레일러가 된다. 성장 3단계를 순서대로 보여줄 것
- 태그: Idler, Clicker, Incremental, Relaxing, Minimalist, Abstract, Procedural Generation, Singleplayer
- 설명: 한국어, 영어

## 3. 빌드 / 기술

- Windows x64 필수. Linux는 Unity 빌드로 저비용 추가 가능. Steam Deck 확인(Proton) 권장. 증분 게임은 Deck 사용 비율이 높다
- Steamworks.NET 연동: 도전과제, 클라우드 세이브, 오버레이
- 도전과제 20~40개. 증분 게임 유저에게 사실상 필수 콘텐츠
- 클라우드 세이브: 로컬 세이브 파일 경로 지정 (Auto-Cloud)
- 창 모드/전체 화면, 해상도, 프레임 제한(방치 중 GPU 낭비 방지), 백그라운드 실행 시 저부하 모드

## 4. 옵션 / 접근성

- 광과민성 옵션: 플래시와 폭발 연출 강도 0~100%. 파티클 기반 게임이므로 필수
- 숫자 표기법 선택
- UI 스케일
- 색약 모드는 색으로만 정보를 전달하지 않으면 생략 가능

## 5. 가격 / 마케팅 (제안)

- 가격 $2.99~4.99. 지역 가격은 Steam 권장값 사용
- 출시 할인 10~15%
- Next Fest 참가 시 데모 빌드 필요(1시간 분량). 개발 기간이 1~2주 늘지만 찜 확보에 가장 효과적
- 커뮤니티: r/incremental_games (자체 홍보 규칙 확인), 국내 커뮤니티, 개발 타임랩스 영상
- 리뷰 확보: 출시 초기 리뷰 10개가 "긍정적" 표시의 기준

## 6. 출시 전 최종 점검

- [ ] 세이브 마이그레이션 테스트 (구버전 세이브 로드)
- [ ] 오프라인 진행 시간 계산 검증 (시스템 시계 조작 대응)
- [ ] 24시간 방치 후 메모리와 성능 확인
- [ ] 큰 수 오버플로 구간 확인 (1e308 전후)
- [ ] 도전과제 전부 달성 가능 확인
- [ ] 외부 테스터 3명 이상, 엔딩 도달 시간 기록
