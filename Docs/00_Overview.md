# 00. 프로젝트 개요

| 항목 | 값 |
|---|---|
| 상태 | 검토중 |
| 최종 수정 | 2026-09-16 |
| 결정 필요 | 테마/비주얼 엔진, 핵심 반복 행동, 엔딩과 목표 시간, 가격, 이름 |

## 1. 한 줄 정의

외부 아트 에셋 없이, **수식으로 생성되는 비주얼**이 곧 성장의 표현이 되는 소규모 증분(incremental) 게임. 1인 개발, Steam 출시.

## 2. 확정 사항

- 장르: 증분 / 방치 (incremental, idle)
- 플랫폼: PC, Steam. Windows 우선
- 개발: 1인, 속도 우선
- 그래픽: 외부 아트에 의존하지 않는다. 수식과 알고리즘으로 생성되는 절차적 비주얼이 핵심 표현이다
- 엔진: Unity 6000.0.66f2, 2D URP, Input System
- 레퍼런스: 일반적인 증분 게임 전반
- 플레이 경험: 플레이 타임은 길지 않다. 특정 시점에 "폭발적 성장"을 체감시켜야 한다

## 3. 미확정 사항

| 결정 | 선택지 | 관련 문서 |
|---|---|---|
| 테마 / 비주얼 엔진 | 우주, 프랙탈, 곡선, 세포 자동자, 네트워크 | 01 |
| 핵심 반복 행동 | 클릭, 타이밍, 배분, 선택 | 02 |
| 엔딩 유무 | 엔딩 있음 + 엔들리스 / 엔딩 없음 | 02 |
| 가격 | 유료 $2.99~4.99 / 무료 | 03 |
| 프로젝트 이름 | 미정. 현재 `_Incremental` | - |

## 4. 목표 (제안)

| 항목 | 제안값 | 근거 |
|---|---|---|
| 엔딩까지 플레이 시간 | 4~8시간 | Nodebuster, The Gnorp Apologue 등 소규모 Steam 증분 게임이 성공한 구간 |
| 프레스티지 레이어 | 2개 | 1개는 얕고, 3개부터 개발과 밸런스 비용이 급증 |
| 가격 | $2.99~4.99 | 동급 게임 가격대 |
| 개발 기간 | 10~12주 | 아래 마일스톤 |
| 언어 | 한국어, 영어 | 증분 게임 커뮤니티는 영어권 중심. 중국어 간체는 추후 검토 |

## 5. 설계 원칙 (제안)

1. **숫자가 곧 그림.** 모든 자원과 배율은 화면의 무언가에 직접 대응한다. 별도 연출을 따로 만들지 않는다.
2. **5분 안에 커지는 느낌, 1시간 안에 첫 프레스티지.**
3. **데이터 주도.** 밸런스 값은 코드가 아니라 데이터에 둔다. 헤드리스 시뮬레이터로 밸런스를 검증한다.
4. **만들지 않는 것.** 스토리, 캐릭터, 손그림 아트, 멀티플레이, 모바일, 3번째 프레스티지 레이어.

## 6. 마일스톤 (제안, 12주)

| 주차 | 목표 | 산출물 |
|---|---|---|
| 1 | 컨셉 확정, 룩 테스트 | 후보 2개의 비주얼 프로토타입 (버리는 씬) |
| 2~3 | 핵심 루프 | 생성기, 업그레이드, 큰 수, 저장. UI만으로 플레이 가능한 상태 |
| 4~5 | 비주얼 엔진 연결 | 숫자 → 비주얼 매핑, 마일스톤 연출, 광과민성 옵션 |
| 6~7 | 프레스티지 1, 밸런스 | 시뮬레이터, 첫 밸런스 패스 |
| 8~9 | 프레스티지 2, 엔딩 | 엔딩 연출, 엔들리스 |
| 10 | Steam 연동 | 도전과제, 클라우드 세이브, 빌드 파이프라인 |
| 11 | 스토어 페이지, 폴리시 | 캡슐, 스크린샷, 트레일러, 옵션 |
| 12 | 테스트, 출시 | 외부 테스트, 버그 수정, 출시 |

스토어 페이지는 출시 최소 2주 전에 공개되어야 한다. 찜을 모으려면 더 일찍이 좋으므로 8주차부터 페이지 준비를 병행한다 (03 참고).
