# 00. 프로젝트 개요

| 항목 | 값 |
|---|---|
| 상태 | 검토중 |
| 최종 수정 | 2026-09-16 |
| 결정 필요 | 경제 구조(E1), 프레스티지(E4), 엔딩 조건(E5), 가격(D5), 이름(D7) |

## 1. 한 줄 정의

우주를 떠도는 먼지를 **홀드로 만든 중력**으로 끌어모아 행성을 만들고 판다. 외부 아트 없이 파티클과 수식만으로 성장을 보여주는 소규모 증분(incremental) 게임. 1인 개발, Steam 출시.

## 2. 확정 사항

- 장르: 증분 / 방치 (incremental, idle)
- 플랫폼: PC, Steam. Windows 우선
- 개발: 1인, 속도 우선
- 그래픽: 외부 아트에 의존하지 않는다. 파티클과 수식 기반 절차적 비주얼이 핵심 표현이다
- 엔진: Unity 6000.0.66f2, 2D URP, Input System
- **테마: 우주. 먼지 → 중력 → 행성** (D1, 2026-09-16 결정)
- **핵심 반복 행동: 마우스 홀드로 중력 생성. 먼지를 끌어모아 행성을 만들고 판매** (D2, 2026-09-16 결정)
- **엔딩: 있음 + 엔들리스** (D4, 2026-09-16 결정)
- 업그레이드 축: 먼지 생성 빈도, 필요 먼지 수, 모으는 힘, 판매 비용, 행성 해금
- 플레이 경험: 플레이 타임은 길지 않다. 특정 시점에 "폭발적 성장"을 체감시켜야 한다

핵심 루프 상세는 [10_Core_Loop.md](10_Core_Loop.md).

## 5. 설계 원칙 (제안)

1. **숫자가 곧 그림.** 모든 자원과 배율은 화면의 무언가에 직접 대응한다. 별도 연출을 따로 만들지 않는다.
2. **5분 안에 커지는 느낌, 1시간 안에 첫 프레스티지.**
3. **홀드는 초반의 재미이지 후반의 의무가 아니다.** 30분 안에 방치 경로가 열리고, 후반은 시스템이 대신 모은다.
4. **데이터 주도.** 밸런스 값은 코드가 아니라 데이터에 둔다. 헤드리스 시뮬레이터로 밸런스를 검증한다.
5. **만들지 않는 것.** 스토리, 캐릭터, 손그림 아트, 멀티플레이, 모바일, 3번째 프레스티지 레이어, 먼지 종류(보류).
