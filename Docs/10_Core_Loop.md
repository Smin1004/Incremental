## 1. 한 문장 (확정)

**먼지를 끌어모아 행성을 만들어낸다.**

## 2. 루프 (확정)

```
런 시작 (스태미나 가득, 먼지 초기 배치)
→ 홀드하면 스태미나가 닳고 그 지점에 중력이 생긴다
→ 먼지가 끌려와 모인다
→ 놓으면 모인 질량만큼의 행성이 생성되고 즉시 런 수입에 합산된다. 행성은 궤도로 떠난다
→ 스태미나 0 → 런 종료
→ 결과 화면: 이번 런의 행성들이 중심 항성을 공전하는 태양계 (런 수입, 지난 런 대비 배율)
→ 스킬트리 (스탯 노드, 행성 해금 관문)
→ 다음 런. 더 많은 먼지, 더 강한 중력, 더 긴 런, 더 큰 행성
```

구조는 **런 기반** (E7, 2026-09-17 결정). 레퍼런스는 Bills Must Be Paid.

## 3. 구성 요소

### 3.1 먼지

확정
- 화면 안 임의 위치에 생성되어 느리게 표류한다.
- 생성 빈도는 업그레이드 대상.

제안
- **화면 상한을 둔다.** 초기 300개, 업그레이드로 3,000~5,000개. CPU(Burst)로 충분하다.
- **"필요 먼지 수"는 질량 단위로 계산한다.** 먼지 1개의 질량이 업그레이드로 오르면 화면 먼지 수는 그대로여도 더 큰 행성이 된다. 시각 캡을 넘어서도 성장을 표현하는 수단이다.
- 생성 분포는 "빈 곳 우선". 커서 반경 안에는 생성하지 않는다.
- 런 사이에 먼지는 리셋된다. 런 시작 시 초기 배치로 빈 화면을 막는다.

### 3.2 중력 (홀드)

확정
- 홀드 시작 시 중력이 생긴다. 모으는 힘은 업그레이드 대상.
- 홀드 중 스태미나가 닳는다. 스태미나가 곧 홀드의 제한이다.

제안
- 중력원은 홀드 중 커서를 따라 움직인다.
- 홀드 중 커서 위에 **형성 중인 천체**가 자란다. 외형은 지금 놓으면 나올 티어다. 임계를 넘으면 다음 티어 외형으로 바뀐다 ([14](14_Planet_Visual_Spec.md) §4).
- 파라미터: 반경, 세기, 포획 반경.
- 스태미나는 런 중 항상 조금씩 닳고(기본 0.2/초), 홀드 중 더 닳는다(1/초). 가만히 있어도 닳는 이유는 먼지가 찰 때까지 무한정 기다리는 플레이를 막기 위해서다.
- 접근성: 홀드 대신 클릭 토글 옵션.

### 3.3 행성 생성

확정
- 모인 먼지가 N개 이상이면 행성이 생성된다. N은 업그레이드로 줄어든다.
- 상위 행성은 해금한다.

제안
- **놓으면 생성.** 티어는 질량이 넘은 임계 중 가장 높은 해금 티어. 오래 홀드할수록 큰 행성. 해금된 최고 티어 임계에 닿으면 놓지 않아도 생성된다. 티어 1 미만이면 먼지가 흩어져 돌아가고 손해는 스태미나뿐이다.
- 행성 종류는 질량으로 결정한다 (E2 기본값). 먼지 종류, 확률 방식은 보류.
- **질량 초과분.** 최고 해금 티어로 생성할 때는 `floor(질량 / 임계)`개가 한 번에 생성된다 (화면에는 행성 하나 + `×N`). 나머지는 버린다. 하위 티어에서 놓을 때의 초과분은 그대로 버린다. 임계에 맞춰 놓는 것이 손맛이다 (2026-09-18, 2주차 보고 §3-2).
- **특이 천체.** 낮은 확률로 변종이 나오고 판매가 ×5~×20. 도전과제 소재. 프로토타입 이후.

### 3.4 천체 티어표 (제안, 전부 조정 대상)

| 티어 | 천체 | 필요 질량 | 기본 판매가 | 비고 |
|---|---|---|---|---|
| 1 | 소행성 | 10 | 1 | 시작 |
| 2 | 혜성 | 25 | 6 | 꼬리 파티클 |
| 3 | 왜소행성 | 60 | 40 | |
| 4 | 위성 | 150 | 250 | |
| 5 | 암석 행성 | 400 | 2,000 | |
| 6 | 지구형 행성 | 1,000 | 15,000 | 파랑, 구름 노이즈 |
| 7 | 가스 행성 | 2,500 | 1.2e5 | 띠 무늬, 고리 |
| 8 | 갈색 왜성 | 6,000 | 1e6 | 희미한 발광 |
| 9 | 적색 왜성 | 15,000 | 1e7 | **항성 점화.** 화면이 밝아진다 |
| 10 | 태양형 항성 | 40,000 | 1e8 | |
| 11 | 청색 거성 | 1e5 | 1e9 | **초신성 = 엔딩** |

- 티어당 판매가 ×6~×10, 필요 질량 ×2.5~3. 모든 값이 double 안에 있다.
- 행성 비주얼은 전부 절차적: 원 + 셰이더(노이즈, 띠, 글로우, 고리). 스프라이트 없음. 티어별 외형은 [14_Planet_Visual_Spec.md](14_Planet_Visual_Spec.md) §3.

### 3.5 판매 (확정)

- 행성 종류에 따라 재화. 판매가는 업그레이드 대상.
- 생성 즉시 런 수입에 합산된다. 수동 판매 버튼은 없다 (E3 종결, 런 기반의 귀결).
- 행성 하나의 수입은 `판매가 × 판매 배율` 그대로다(소수 허용). **런이 끝날 때 `ceil(런 수입)`을 재화에 더한다.** 재화는 항상 정수다. 행성 단위로 올리면 티어 1에서 "+25%"가 +100%가 되어 런 단위로 옮겼다 (2026-09-18, 14 §8).
- 행성은 잠시 자전하다가 화면 우상단의 소실점으로 떠난다. 결과 화면의 태양계가 그 행선지다 ([13_Result_SolarSystem_Spec.md](13_Result_SolarSystem_Spec.md)). "판매"라는 표시 문구는 추후 조정한다 (D10).

## 4. 런 구조와 후반

### 4.1 런 (확정)

| 항목 | 내용 |
|---|---|
| 런 시작 | 스태미나 가득. 먼지 초기 배치. 질량 0 |
| 런 중 | 홀드, 생성, 즉시 합산. 상점 없음 |
| 런 종료 | 스태미나 0. 홀드 중이었다면 강제 생성 후 종료 |
| 결과 화면 | **태양계.** 이번 런의 행성들이 중심 항성을 공전한다. 패널에 런 수입, 티어별 행성 수, **지난 런 대비 배율**, 최고 기록 (S13, [13](13_Result_SolarSystem_Spec.md)) |
| 스킬트리 | 스탯 노드와 관문 노드. 런 사이에만 (S14, [12](12_SkillTree_Spec.md)) |
| 유지되는 것 | 재화, 업그레이드 레벨, 해금, 런 통계, 도전과제 |
| 리셋되는 것 | 먼지, 스태미나, 질량 |

- 런 길이: 초반 1분, 후반 5~10분. 엔딩까지 약 40~70런.
- 결과 화면의 "지난 런 대비 배율"이 성장 그래프다. 매 런 1.0을 넘게 유지하는 것이 밸런스 목표. 비교 대상은 가장 최근의 스태미나 종료 런이다. 중간에 끈 런(quit, crash)은 배율과 최고 기록에서 뺀다. ×1,000 이상은 `×347M`처럼 줄여 쓴다.
- 런 중 정상 종료(quit) 때 홀드 중이던 질량은 스태미나 종료와 같이 강제 생성한다.
- 런 중 업그레이드 구매는 만들지 않는다. 런은 플레이, 스킬트리는 결정으로 분리한다. 프로토타입 후 필요하면 재검토.

### 4.2 방치 경로 (E1, 불필요)

런 기반이므로 방치 경로도 오프라인 진행도 없다. 후반의 증폭은 스태미나 상한, 먼지 질량, 판매 배율이 담당한다.

### 4.3 폭발적 성장의 순간

시스템에서 나오는 순간 4개.

1. **매 런의 결과 화면.** 지난 런 대비 ×2, ×3이 찍히고, 지난 런보다 붐비는 태양계가 보이는 순간.
2. **먼지 폭증 (15~20분).** 먼지 상한과 중력 반경 업그레이드가 같은 구간에 오도록 배치해, 화면이 먼지로 가득 차는 첫 런을 만든다.
3. **항성 점화 (1~2시간).** 티어 9 생성 시 화면 전체가 밝아지고 배경 색이 바뀐다.
4. **초신성 (엔딩, 2~4시간).** §4.4.

### 4.4 엔딩 (E5, 기본값)

- 조건: 티어 11(청색 거성) 생성.
- 연출: 항성이 붕괴 → 폭발 → 화면 전체로 먼지 방출 → 크레딧. 연출 강도 옵션 적용.
- 이후 엔들리스: 같은 세이브로 계속. 도전과제 마무리. 새 시스템은 없다.

### 4.5 프레스티지 (E4, 기본값 없음)

2~4시간 게임은 단일 진행 + 엔딩으로 충분하고 레퍼런스에도 없다. 넣는다면 엔딩 후 "새 성운"(NG+) 1개로, 영구 배율만 주고 새 시스템은 만들지 않는다. 런 종료 시 3택1 퍽(S3)은 분량이 부족할 때의 보강 카드로 보관.

## 6. 화면 구성 (제안)

- 런 화면: 우주(먼지, 행성)가 전부. 상단 스태미나 바, 모서리에 재화와 런 수입. 업그레이드 UI 없음.
- 결과 화면: 태양계 + 좌측 패널 ([13](13_Result_SolarSystem_Spec.md)).
- 스킬트리 화면: 별자리 형태 ([12](12_SkillTree_Spec.md) §9).
- 흐름: 결과 → Space → 스킬트리 → Space → 다음 런. 아무것도 사지 않으면 3초 안에 다음 런.
- 배경은 검정에 가까운 남색 + 절차적 별 노이즈. 항성 점화 후 색이 바뀐다.
