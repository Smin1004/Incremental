# 10. 핵심 루프: 먼지, 중력, 행성

| 항목 | 값 |
|---|---|
| 상태 | 골격 확정 (1~3절의 "확정" 표기) + 세부 제안 |
| 최종 수정 | 2026-09-16 |
| 결정 필요 | E1 경제 구조, E2 행성 종류 결정 방식, E3 판매 방식, E4 프레스티지, E5 엔딩 조건, E6 홀드 제한 |

## 1. 한 문장 (확정)

**먼지를 끌어모아 행성을 만들어낸다.**

## 2. 루프 (확정)

```
먼지가 화면을 떠돈다
→ 플레이어가 마우스를 홀드하면 그 지점에 중력이 생긴다
→ 먼지가 끌려와 모인다
→ N개 이상 모이면 행성이 생성된다
→ 행성 종류에 따라 재화를 얻는다 (소행성은 n, 지구는 n)
→ 재화로 업그레이드
→ 더 많은 먼지, 더 강한 중력, 더 큰 행성
```

## 3. 구성 요소

### 3.1 먼지

확정
- 화면 안 임의 위치에 생성되어 느리게 표류한다.
- 생성 빈도는 업그레이드 대상.

제안
- **화면 상한을 둔다.** 상한이 없으면 성능과 밸런스 둘 다 통제할 수 없다. 초기 200개, 업그레이드로 5,000개, GPU 전환 후 10만 개.
- **"필요 먼지 수"는 질량 단위로 계산한다.** 먼지 1개의 질량이 업그레이드로 오르면, 화면에 보이는 먼지 수는 그대로여도 더 큰 행성이 만들어진다. 이것이 시각 캡을 넘어서도 성장을 표현하는 수단이다.
- 파라미터: 생성 빈도(초당), 화면 상한(개), 1개당 질량, 표류 속도, 크기와 밝기.

### 3.2 중력 (홀드)

확정
- 홀드 시작 시 중력이 생긴다. 모으는 힘은 업그레이드 대상.

제안
- **중력원은 홀드 중 커서를 따라 움직인다.** 고정이면 "놓고 기다리기"가 되어 초반 재미가 사라진다.
- 파라미터: 반경(영향 범위), 세기(가속도), 포획 반경(이 안에 들어온 먼지는 "모인 것"으로 집계).
- **E6: 홀드 시간 제한이나 에너지 게이지를 두지 않는다.** 커서 근처 먼지가 고갈되므로 자연히 커서를 옮기게 된다. 이것이 초반 10~30분의 "사냥" 재미다. 제한을 두면 재미가 아니라 의무가 된다.
- 접근성: 홀드 대신 클릭 토글 옵션. 몇 시간 홀드는 손목에 무리다.
- 홀드 중 커서 주위에 반경 표시. 포획된 질량이 원형 게이지로 차오르고, 임계에 닿으면 행성이 튀어나온다.

### 3.3 행성 생성

확정
- 모인 먼지가 N개 이상이면 행성이 생성된다. N은 업그레이드로 줄어든다.
- 상위 행성은 해금한다.

제안
- **E2: 행성 종류는 모인 질량으로 결정한다.** 홀드를 계속하면 질량이 쌓여 상위 천체가 된다. 해금하지 않은 티어의 임계에 닿으면 그 직전 티어로 자동 생성된다(더 쌓이지 않음). 해금이 곧 "더 오래 모을 수 있는 권리"가 된다.
- **특이 천체.** 낮은 확률로 금속 소행성, 다이아몬드 행성 같은 변종이 나오고 판매가가 ×5~×20. 확률은 업그레이드. 구현 비용이 거의 없이 흥분 요소를 준다.
- 보류: 먼지 종류(얼음, 암석, 가스)로 행성 종류를 정하는 안. 비주얼 다양성은 좋지만 UI와 밸런스 비용이 크다. 프레스티지 2 이후 콘텐츠로 검토.

### 3.4 천체 티어표 (제안, 전부 조정 대상)

| 티어 | 천체 | 필요 질량 | 기본 판매가 | 비고 |
|---|---|---|---|---|
| 1 | 소행성 | 10 | 1 | 시작 |
| 2 | 혜성 | 25 | 6 | 꼬리 파티클 |
| 3 | 왜소행성 | 60 | 40 | |
| 4 | 위성 | 150 | 250 | |
| 5 | 암석 행성 | 400 | 2,000 | |
| 6 | 지구형 행성 | 1,000 | 15,000 | 파랑, 구름 노이즈 |
| 7 | 가스 행성 | 2,500 | 1.2e5 | 띠 무늬, 고리 |
| 8 | 갈색 왜성 | 6,000 | 1e6 | 희미한 발광 |
| 9 | 적색 왜성 | 15,000 | 1e7 | **항성 점화.** 화면이 밝아진다 |
| 10 | 태양형 항성 | 40,000 | 1e8 | |
| 11 | 청색 거성 | 1e5 | 1e9 | **초신성 = 프레스티지 1 트리거** |

- 티어당 판매가 ×6~×10, 필요 질량 ×2.5~3.
- 먼지 1개 질량이 오르므로 티어 11도 화면 먼지 수백 개로 만들 수 있게 된다.
- 행성 비주얼은 전부 절차적: 원 + 셰이더(노이즈, 띠, 글로우, 고리). 스프라이트 없음.

### 3.5 판매

확정
- 행성 종류에 따라 재화. 판매가는 업그레이드 대상.

제안
- **E3: 수동 판매로 시작, 티어별 자동 판매를 업그레이드로 해금.** 초반엔 "팔았다"는 손맛, 후반엔 자동화. 증분 장르의 표준 흐름.
- 설정 문제: "누가 행성을 사가는가"는 설명하지 않아도 된다. 굳이 피하려면 재화를 "에너지"나 "질량"으로 부르고 행성이 그것을 방출한다고 해석할 수 있다. 결정은 개발자.

## 4. 빠져 있는 부분과 제안

### 4.1 방치 경로 (가장 큰 공백, E1)

현재 루프는 100% 능동이다. 홀드를 놓으면 아무 일도 없다. 증분 게임은 놓아도 굴러가야 하고, 오프라인 진행도 필요하다. 두 가지 안.

| | A. 자동 중력원 | B. 행성이 생성기 |
|---|---|---|
| 내용 | 위성이나 탐사선을 사면 고정 위치에 중력원이 상시 존재한다 | 생성된 행성이 궤도에 남아 스스로 먼지를 끌어모으고 성장한다. 판매하면 사라진다 |
| 장점 | 단순하다. 기존 증분 문법 그대로 | "행성을 만든다"는 핵심과 하나가 된다. 화면의 행성 수가 곧 수입이다. 팔까 키울까의 선택이 생긴다 |
| 단점 | 추상적 구매물이 하나 더 생긴다 | 밸런스 변수가 늘어난다. 궤도 슬롯 제한이 필요하다 |
| 구현 | 0.5일 | 1.5일 |

**추천: B.** 설계 원칙 1(숫자가 곧 그림)에 가장 부합한다. 궤도 슬롯(초기 1~2개, 업그레이드로 증가)이 "팔아서 자리를 비울 것인가, 키울 것인가"라는 결정을 만든다. 슬롯이 꽉 차면 새 행성은 자동 판매된다. 궤도 행성이 먼지를 흡수해 티어가 오르면 "생성기가 생성기를 키우는" 연쇄 성장이 되고, 이것이 폭발적 성장의 엔진이 된다.

B가 2주차 프로토타입에서 혼란스러우면 A로 후퇴한다.

### 4.2 폭발적 성장의 순간

별도 연출이 아니라 시스템에서 나오는 순간을 4개 잡는다.

1. **먼지 폭증 (15~20분).** 먼지 상한과 중력 반경 업그레이드가 같은 구간에 오도록 배치해, 화면이 먼지로 가득 차는 첫 순간을 만든다.
2. **항성 점화 (1~2시간).** 티어 9 생성 시 화면 전체가 밝아지고 배경 색이 바뀐다. 궤도 행성들이 항성 주위를 돈다.
3. **초신성 (프레스티지 1).** 4.3.
4. **은하 스케일 전환 (프레스티지 2).** 카메라가 줌아웃되고, 지금까지의 "먼지"가 "별"이 된다. 4.4.

### 4.3 프레스티지 1: 초신성 (제안, E4)

- 조건: 티어 11(청색 거성) 생성.
- 연출: 항성이 붕괴 → 폭발 → 화면 전체로 먼지 방출 → 리셋. 광과민성 옵션 적용.
- 획득: **중원소(heavy elements).** 실제로 무거운 원소는 초신성에서 만들어진다. 테마와 정확히 맞는다.
- 사용: 영구 배율(먼지 질량, 판매가), 중원소 전용 업그레이드 트리, 티어 해금 조건(예: 지구형 행성은 중원소 필요).
- 리셋: 먼지, 행성, 재화, 일반 업그레이드. 유지: 중원소, 중원소 업그레이드, 도전과제.
- 첫 초신성 목표 시각: 45~90분.

### 4.4 프레스티지 2: 은하 (제안, E4)

- 조건: 초신성 N회 또는 중원소 누적.
- 연출: 남은 잔해가 블랙홀이 되고 카메라가 줌아웃. 화면의 점 하나하나가 이제 별이다.
- 루프는 동일하다. 별(먼지)을 끌어모아 성단과 성계(행성)를 만든다. 명칭과 티어표만 바뀐다. 코드 재사용.
- 획득: 은하 화폐 → 규칙 변경(먼지 종류, 중력 특성), 엔딩 경로.
- 첫 은하 목표 시각: 3~4시간.

### 4.5 엔딩 (제안, E5)

- 조건: 은하 완성. 예를 들어 은하 단계의 마일스톤(나선팔 4개) 전부 달성. 5~8시간.
- 연출: 완성된 은하를 줌아웃하며 보여주고 크레딧.
- 이후 엔들리스: 같은 세이브로 계속. 은하 화폐로 무한 스케일 업그레이드. 도전과제 마무리.

### 4.6 오프라인 진행

- 물리 시뮬레이션을 오프라인으로 돌릴 수 없다. 궤도 행성의 기대 흡수율 × 시간으로 수식 계산한다.
- 이 수식은 밸런스 시뮬레이터와 공유한다. 실제 플레이와 오프라인 계산이 크게 어긋나면 리뷰에서 지적된다.

## 6. 화면 구성 (제안)

- 화면 대부분은 우주(먼지, 행성). UI는 가장자리 패널로 최소화한다.
- 좌: 재화, 업그레이드 목록. 우: 궤도 행성 목록과 판매 버튼. 하단: 다음 티어까지의 질량 게이지.
- 배경은 검정에 가까운 남색 + 절차적 별 노이즈. 항성 점화 후 색이 바뀐다.

## 7. 1주차 프로토타입 범위 (구현 세션 인계용)

- 먼지 생성과 표류, 홀드 중력, 포획 집계, 임계 도달 시 행성 스폰(원 하나), 티어 3개, 판매 버튼, 재화 표시, 업그레이드 3개(빈도, 힘, 판매가).
- 궤도(B안)는 프로토타입에서 제외. 홀드 자체의 손맛만 확인한다.
- 합격 기준: 5분 플레이 후 "한 번만 더"가 나오는가. 60fps. 이 화면이 스크린샷으로 쓸 만한가.
