# 능력 프로토타입 수정 1차 (구현 세션용)

2026-09-30. 개발자 확인 뒤 나온 버그 2건과 유성 보정이다.

> **따로 보내지 않았다면 보내지 않는다.** 같은 내용이 [Abilities_Proto2.md](Abilities_Proto2.md)의 A에 들어 있다.

```text
능력 프로토타입 수정 1차: 버그 2건과 유성 보정. abilities 브랜치에서 이어서 한다.

[버그 1] 중력 영향권 안에서 생성된 먼지에 꼬리가 갑자기 생긴다.
[버그 2] 간헐적으로 화면 전체의 꼬리가 중앙으로 선을 긋는 듯한 형태가 나온다.

기획 쪽 추정이다. 사실인지 먼저 확인해라.
- 둘 다 먼지 슬롯이 재사용될 때 궤적 링 버퍼와 번짐에 쓰는 이전 상태가 초기화되지 않는 문제일 수 있다. 중앙에서 잡혀 사라진 먼지의 슬롯을 화면 곳곳의 새 먼지가 물려받으면, 새 먼지의 궤적이 옛 위치(중앙)에서 새 위치까지 선을 긋는다.
- 버그 2가 수축 발동과 같은 순간인지 [Ability] 로그로 먼저 가려라. 같은 순간이면 버그가 아니라 수축의 번짐이 그렇게 보이는 것이다. 그 경우 고치지 말고 보고서에 적어라.

고치는 방향:
- 먼지가 생성될 때 궤적 버퍼의 모든 점을 생성 위치로 채우고, 번짐에 쓰는 이전 상태도 초기화한다. 꼬리는 0에서 자라야 한다.
- 생성 직후 짧게(기본 0.2초) 밝기를 0에서 올린다. 값은 GameParams에 둔다.
- 먼지 생성 규칙(어디에 생기는지)은 바꾸지 마라. 처리량이 바뀐다.

[유성 보정] 플레이어와 너무 먼 곳을 긁고 지나갈 때가 있다.
- passMaxRadii 2.5 → 1.5.
- 유성이 화면 안에 있는 동안 현재 중력원 쪽으로 살짝 휜다. AbilityTable에 homingDegPerSec(기본 12)를 두고, 0이면 직선이다.
- 경로를 정하는 기준은 지금처럼 발동 순간의 중력원 위치다. 휘는 것은 그 뒤에 플레이어가 움직인 만큼을 따라가려는 것이다.

[지킬 것]
- 새 테스트, 완주 런, 성능 측정은 하지 않는다. 기존 테스트는 마지막에 한 번만 돌린다.
- 수축과 위성은 건드리지 마라. 개발자가 방향을 정하는 중이다.
- 커밋 메시지는 한국어로 쓴다.

[끝나면]
Docs/Reports/Abilities_Proto.md 끝에 "수정 1차" 절을 붙여 원인, 고친 것, 바꾼 값을 짧게 적어라.
```

## 판단

- 두 버그의 원인을 하나로 추정했다. 링 11 캡처와 증상("화면 전체", "중앙으로")이 슬롯 재사용과 맞는다. 다만 수축의 번짐과 모양이 같아서, 로그로 먼저 가리게 했다.
- 생성 위치 규칙은 막았다. 영향권 안 생성을 금지하면 보기에는 깔끔하지만 처리량이 바뀐다. 밸런스는 마지막 패스에서 한 번에 본다.
- 유성은 거리 상한과 약한 유도를 같이 넣었다. 상한만 줄이면 발동 뒤 플레이어가 움직였을 때 여전히 멀어진다.
