12차: 궤도석 궤도를 중력원 기준으로, 시각 보강(배경·왜곡·이펙트). main 브랜치에서 한다.

[이번 작업의 성격]
프로토타입이다. 그림만 바꾸고 처리량(포획, 수입, 시간)은 바꾸지 않는다. 봇 런, 밸런스, 빌드 성능 측정, 새 테스트는 하지 않는다. 기존 테스트는 마지막에 한 번, Validate Data는 체크포인트마다.

[A. 궤도석 궤도 (24 §24.5)]
원인을 먼저 캡처로 확인한다: 빛 꼬리(TrailRenderer)가 월드 좌표에 쌓여 중력원이 움직이면 끌린다, Render의 중심이 고정 틱 위치라 한 틱 늦다.
- 꼬리를 궤도 호로: 지금 중심 + 같은 타원의 θ − Δ 구간을 매 프레임 계산해 그린다(Δ = trailSec 동안 지나온 각도). 폭·색·끝 투명·연출 강도는 지금 꼬리와 같게.
- 그리는 중심을 중력 고리와 같은 보간 위치로.
- AbilityTable.satellite.trailInOrbitFrame(켬, 끄면 예전).
- 바꾸지 않는 것: 궤도 모양, 끌어당김·견인, 범위 안에서 놓기, 결정 버프 중 궤도가 커지는 것.

[B. 렌즈 칸 4개 (26 §12.2)]
Lens.hlsl의 전역 렌즈를 4칸으로 늘린다: 0 블랙홀, 1 중력원, 2 수축 파동, 3 묶음 일렁임. 칸마다 중심, 반지름, 세기, 모양(밀기 / 고리 띠 / 회전). Starfield, Dust, DustTrail이 네 칸을 읽는다. 화면 복사 없음, Camera Sorting Layer Texture는 켜지 않는다.
- D1 중력원 렌즈 (기본 켬): 홀드 중, 반지름 = 중력 반지름 × 0.8, 세기 0.2 × (모은 질량 / 임계값) × (1 + 링 × 0.05), 놓으면 0.3초에 풀림. 원판 지우기 없음.
- D3 블랙홀 소용돌이 (기본 켬): 블랙홀 렌즈에 회전 더하기, 가장자리 40° → 도달 거리 0°, 먼지 소용돌이와 같은 방향.
- D2 수축 파동 일렁임 (기본 끔): 수축 고리 자리의 띠(폭 0.15 × 파동 반지름, 세기 0.15).
- D4 ×N 묶음 일렁임 (기본 끔): 묶음 자리에서 0.4초 퍼지는 물결 띠, 세기 ∝ log N.

[C. 배경 (26 §12.1)]
- B1a 옅은 성운 (기본 켬): 엔딩 뒤에만 켜던 성운을 평소에도 옅게(backdropNebulaStrength 0.25 × 엔딩 세기). 색은 지금 배경 팔레트. 먼지보다 눈에 띄면 안 된다.
- B2 시차 (기본 켬): 중력원이 중심에서 벗어난 만큼 먼 별 0.005, 가까운 별 0.015, 성운 0.003 (화면 크기 비율) 반대로, 0.3초 부드럽게. 런 화면만.
- B3 먼 천체 실루엣 (기본 켬): 화면 구석에 아주 어두운 큰 천체 하나(나선 은하 / 고리 달린 거대 행성 가장자리 / 옆으로 누운 은하), 셰이더로, 밝기 0.06 안팎, 천천히 회전. 관문을 사면 다음 것으로.
- B4 성운 소용돌이 (기본 켬): 홀드 중 성운 UV를 중력원 둘레로 비튼다(0.4라디안, 0.5초에 들어오고 놓으면 풀림).
- B1b 링마다 성운 색: 구현하지 않는다. 시안 캡처만: 링 1·6·11 × 팔레트 3안((가) 청록→보라→금·자홍, (나) 링마다 한 색조씩, (다) 최고 티어 색을 강하게) 9장과 B1a만 켠 3장. 런타임에 Starfield 값만 바꿔 찍는다(코드 커밋 없음).

[D. 이펙트 (26 §12.3)]
- E2 ×N 숫자 팝 (기본 켬): 1.6배 → 1배 0.25초, 크기 ∝ log N, 색 흰 → 금 → 주황(×3, ×10, ×30), 1초 안의 연속 묶음은 같은 라벨 숫자가 굴러 올라간다(합계).
- E4 홀드 시작·끝 (기본 켬): 누를 때 고리 0.85 → 1배 0.2초 + 밝게, 놓을 때 1.15배로 퍼지며 0.25초에 사라짐.
- E5 버프 테두리 (기본 켬): 결정 버프 동안 화면 가장자리 12%에 금빛 테두리 알파 0.08, 천천히 맥동, 남은 시간에 따라 옅어짐, 공명 2중첩이면 조금 진하게.
- E1 히트스톱 + 흔들림 (기본 끔): ×N(N ≥ 5), 새 티어 첫 완성, 블랙홀 방출에 시뮬레이션 0.05초 멈춤(입력·그림은 계속) + 6px 0.15초 흔들림.
- E3 새 티어 첫 완성 카드: 구현하지 않는다. 링 7~9의 새 티어 완성 캡처 위에 화면 30% 어둡게 + 가운데 티어 이름과 설명 한 줄을 얹은 합성 이미지 2안(카드형 / 글자만). 합성은 스크래치패드 스크립트로.

## 판단

- **찬성 항목은 기본 켬, 고민 항목은 기본 끔으로 같이 만든다.** D2, D4, E1은 D1·D3을 위해 만드는 렌즈 칸과 연출 구조를 그대로 써서 각각 반나절도 안 걸린다. 켜 보고 정하는 쪽이 왕복이 적다.
- **B1b와 E3은 시안만 받는다.** B1b는 "감이 안 잡힌다"는 회신이라 보여 주는 것이 먼저다. 성운 셰이더는 이미 있어서 값만 바꿔 찍으면 된다. E3은 구현 비용이 크고 사운드와 같이 볼 때 판단이 정확하다.
- **B4 때문에 옅은 성운(B1a)을 넣는다.** 성운이 엔딩 뒤에만 켜지므로, 그대로면 소용돌이칠 성운이 없다.
- **렌즈를 4칸으로 늘리는 것이 이번 작업의 뼈대다.** 중력원, 블랙홀, 수축, 묶음이 같은 방식을 공유한다. 화면 복사가 없어 11차에서 되찾은 성능 여유를 쓰지 않는다.
- **D1은 약하게 시작한다.** 먼지가 중력원으로 빨려 드는 모양이 이 게임의 핵심 그림이다. 렌즈가 그것을 흐리면 안 된다.
- **보고서 맨 앞에 "고를 것" 요약을 둔다.** 이번에는 개발자가 고를 것이 많다.
